# 2D 项目 · 千星奇域开发 Skill

> 给 AI Agent 用的 2D 小游戏开发套件。目标：让一个**从未接触过千星奇域**的 Agent
> 在几小时内做出可玩的 2D 游戏（像素画 / 华容道 / 贪吃蛇 / 2048 / 推箱子 …），
> 并避开前人踩过的全部坑。

## 给用户的 30 秒说明

**你能得到什么**：在这个引擎里做出可玩的 2D 小游戏，支持键盘 + 鼠标 + 像素画渲染。

**你需要做什么**（只有 3 件事是必须人工的）：

1. **导入模板**（1 分钟，一次性）
   把 `templates\2D-ready.gil` 复制到你的关卡目录，改名为 `<你的关卡ID>.gil`。
   这一步给了你「图片模板 / 文本框 / 光标检测区域 / 客户端控件容器」——
   没有它们，Agent 什么都建不出来。

2. **部署脚本**（每次 5 秒）
   把 Agent 给你的 `.lua` 拖到 `tools\deploy.bat` 上。

3. **试玩 + 贴日志**（每次 20 秒）
   编辑器里「退出关卡 → 重新进入关卡」，把日志窗口的内容复制给 Agent。

## 精度 ↔ 耗时对照（**Agent 会先让你选**）

| 分辨率 | 控件数（含108²参考图） | 构建耗时 | 观感 |
|---|---|---|---|
| 96×96 | 20,880 | ≈ 5.6 s | 明显像素感 |
| 128×128 | 28,048 | ≈ 8.0 s | 清晰，像素感适中 |
| **160×160** | **37,264** | **≈ 11.2 s** | **清晰（推荐）** |
| 200×200 | 51,664 | ≈ 17.6 s | 很清晰（**仍可 OnStart 一次建完**） |
| 256×256 | 61,440 | ≈ 26 s → 单次会被看门狗中断 ❌ | **改用分帧创建 ✅** |
| 300×300 全屏图 | ≈ 8 万 | 单次 ❌ / 分帧 ≈ 60~90 s ✅ | 很精细 |
| 600×600 全屏图 | ≈ 10 万 | 单次 ❌ / 分帧 ≈ 2~3 分钟 ✅ | 极精细 |

> **★ 决策阈值：50,000 个控件**
> **≤ 50,000 → 推荐 OnStart 一次建完** ✓（实测 20,000 个只需 8.06 s，
> 比分帧创建的 10.78 s **还快 34%**，而且代码简单得多）
> **> 50,000 → 必须用分帧创建** ✓ 完整方法：`examples/大批量控件-分帧创建.md`

> **★ 重要修订（2026-10）**：以前认为"控件数超过 5.2 万就崩溃"，实测证明
> **并没有控件数上限**——限制是「**单次回调约 22 秒**」。
> 超过 50,000 个控件时改用 **分帧创建**（每帧 40 ms，全程隐藏、建完分帧显示）
> 即可跑到 **10 万控件以上**，且全过程不卡死 ✓

**⚠️ 反直觉但重要**：**提高分辨率会让画面更糊**（每个像素占的屏幕点变少 → 摩尔纹更明显）。
如果觉得糊，正确的做法是**降低分辨率**。

## 出问题时的自救

### 关卡一进去就卡死

```powershell
tools\kill.bat 你的关卡ID
```

把脚本换成空脚本，就能安全进关卡了。`.gil` 完全不会被动。

### 部署后没生效

确认你做了「**退出关卡 → 重新进入关卡**」这一步。
`deploy.bat` 会校验哈希，如果它报「哈希不一致」，说明编辑器覆盖了文件，重试一次。
