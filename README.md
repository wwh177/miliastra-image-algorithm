#      千星奇域下基于贪心最大矩形合并-动态阈值的图像压缩算法工具包

### 怎么使用：
    
-  把整个文件丢给你的 `agent`（比如DSH），待其解析完后就可以直接让它操作该工具包

### 能做到什么：

- 能压缩图片从而减少控件的使用量和占用储存
- 能够根据提供的图片计算压缩后占用控件的数量，占用储存空间大小，压缩率以及MAE（画质损失）    
- 要计算请直接把图片以及设定的参数给agent然后叫它计算
- 其余功能请询问你的agent

### 需要设定什么：
- 压缩后图片的分辨率，压缩的STD（STD越大压缩效果越好但失真率越高，STD=1是伪无损压缩）
- 是否开启动态STD： 默认开启。通过你设定的压缩STD来决定动态STD的参数（当然你也可以自行决定，可设定6个参数：`t1_std , t2_std , flat_std , t1 , t2 , flat` 。这些参数用途见 `.README-For_Agent.md`，不懂就别乱改）
- 默认：开启 `base 64` 编码，使文件占用储存减少 `30%`（b64 = 7 字符/块，hex = 10 字符/块）
